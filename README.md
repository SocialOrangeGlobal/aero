# eResearch 2026 Conference Landing Page

This is the landing page for the eResearch Australasia 2026 Conference, built with Next.js, React, and Tailwind CSS.

## Features
- Fully responsive design (Mobile, Tablet, Desktop)
- Custom Tailwind theme configuration matching brand guidelines
- Reusable React components for Navbar, Hero, Main Content, Conference Info, Sponsors, and Footer

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- [Next.js](https://nextjs.org)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [Lucide React](https://lucide.dev) (for icons)
